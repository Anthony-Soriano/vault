# Project Truth Bootstrap (v0.3.2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draft *missing* Project Truth from repository evidence as evidence-backed, non-canonical, **ephemeral** proposals — reusing the `v0.3.1` context analysis and the `v0.3.0` AI proposal pipeline — with cited technical facts separated from owner-input gaps, and no persistence or canonical write path.

**Architecture:** `VaultService` (gaining an optional AI dependency) runs the existing read-only `analyzeProjectContext`, a **pure planner** decides which `.orbit/` docs to target, the existing `AiService.propose` generates `project_truth` proposals, and a **pure mapper** validates citations against the supplied inventory and separates facts from owner-input gaps. The result is returned through one **non-mutating** IPC channel to a read-only renderer view. Nothing is written; the AI layer holds no repository.

**Tech Stack:** TypeScript, pnpm monorepo (`@orbit/vault-types`, `@orbit/vault-core`, `@orbit/vault-storage`, `apps/vault-desktop`), Electron main/preload + React/Vite renderer, `node:sqlite`, Node built-in test runner (`node --experimental-strip-types --test`).

## Global Constraints

- **Scope authority:** `.orbit/CURRENT_PHASE.md` (v0.3.2). Do not implement anything absent from it (AGENTS.md Rule 3).
- **Ephemeral only (decision 2):** no proposal store, no new DB table/migration, no canonical write, no approve/edit/save/merge/replace execution. The slice must contain **no** repository-write and **no** mutating IPC.
- **Existing-stack boundary (decisions 1 & 4):** present docs default to `keep_existing`; emit no change/replacement recommendation (that is `v0.3.5`).
- **Evidence validation (decision 3):** a cited `ref` counts as a technical fact only if it resolves to a `relativePath` in the supplied `ProjectEvidenceInventory`; otherwise it is downgraded to owner-input-needed.
- **Trust invariants:** every draft is an `AiProposal` with `status:"proposed"`; `AiService`/`ProjectTruthBootstrapService` hold **no repository**; project isolation enforced; provider-neutral (gate uses `StubAiProvider`).
- **Planner authority (binding, owner-added 2026-08-07):** the planner is the sole authority over bootstrap scope — which docs exist, which are targeted, their state, and the generation scope. AI fills planner-selected slots only; it may never invent an additional Project Truth document nor silently skip a planner-selected target. Enforced structurally: `mapBootstrapDrafts` iterates the **plan's targets** (never the provider's proposals); unmatched proposals are discarded, unmatched targets still emit a `proposal: null` draft.
- **Ordering is a v0.3.2 implementation detail (future hardening, do NOT implement now):** pairing nth-proposal↔nth-target is acceptable only under the deterministic `StubAiProvider`; long-term, proposals should be matched by an explicit `targetDoc`/stable id, not response order. Documented in the design; not in scope here.
- **Determinism:** the planner and the draft mapper are pure (no clock, no fs, no SQLite). Only `generatedAt`/the model call vary; tests fix the clock via an injected `now`.
- **Verification gate (must be green after each task):** `corepack pnpm typecheck` · `corepack pnpm test` · `corepack pnpm build` · `node scripts/phase2-lifecycle-ui-regression.mjs`.
- **Naming (verbatim):** IPC channel `vault:project-truth:bootstrap`; API facade `projectTruth.bootstrap`; rule tag `PROJECT_TRUTH_BOOTSTRAP_RULE_VERSION`; test suite `tests/phase3-project-truth-bootstrap.test.ts`.
- **Reuse verbatim (do not redefine):** `AiProposal`, `AiProvenance`, `AiEvidenceRef`, `AiContextPackage`, `ProjectContextAnalysis`, `ProjectEvidenceInventory`, `ProjectTruthReadiness`, `AiError`/`ApiResult`, `REQUIRED_TRUTH_DOCS`, `assertIdentifier`, the `handle()`/`call<T>` IPC helpers.

```typescript
// --- Phase 3 / v0.3.2 — Project Truth Bootstrap (pure planner) ---
// Decide which required .orbit/ docs to draft. Pure: no clock, no fs, no model.
// Present docs default to keep_existing and generate nothing (owner decisions 1 & 4).

// NOTE (future hardening, not implemented now): "1" is an acceptable anonymous integer for v0.3.2.
// As bootstrap evolves, future rule versions should become explicit semantic/versioned identifiers
// (distinguishing planner-rule vs mapper-rule changes) rather than an opaque incrementing integer.
export const PROJECT_TRUTH_BOOTSTRAP_RULE_VERSION = "1";

export interface BootstrapTarget {
  targetDoc: string;
  docState: ProjectTruthDocState;
  suggestedDisposition: ProjectTruthDisposition;
  /** Human-readable reason, fed to AiService as the proposal purpose. */
  purpose: string;
  /** Instructions encoding the evidence-boundary rule for this doc. Empty for keep_existing targets. */
  instructions: string;
  /** Ids of contextPackage items relevant to this target (kept for traceability). */
  contextItemIds: string[];
}
export interface BootstrapPlan {
  projectId: string;
  ruleVersion: string;
  targets: BootstrapTarget[];
}

/** Docs whose content is predominantly owner-intent (must be requested, not inferred from code). */
const INTENT_HEAVY_DOCS = new Set([".orbit/PROJECT.md", ".orbit/DECISIONS.md", ".orbit/ROADMAP.md"]);

const bootstrapInstructions = (targetDoc: string): string => {
  const base =
    "Draft ONLY technical facts you can cite to a provided context item. " +
    "For anything about owner intent, product vision, target users, priorities, or the reasons behind decisions, " +
    "do NOT invent content — mark it as needing owner input (set inferred=true and add no fabricated citation).";
  return INTENT_HEAVY_DOCS.has(targetDoc)
    ? `${base} This document is predominantly owner-intent; expect most of it to require owner input.`
    : base;
};

/** Decide bootstrap targets from a read-only ProjectContextAnalysis. Pure/deterministic. */
export function planProjectTruthBootstrap(analysis: ProjectContextAnalysis): BootstrapPlan {
  const present = new Set(analysis.readiness.presentDocuments);
  const itemIds = analysis.contextPackage.items.map(i => i.id);
  const targets: BootstrapTarget[] = REQUIRED_TRUTH_DOCS.map((doc): BootstrapTarget => {
    const targetDoc = `.orbit/${doc}`;
    const isPresent = present.has(targetDoc);
    return isPresent
      ? { targetDoc, docState: "present", suggestedDisposition: "keep_existing", purpose: `Keep existing ${targetDoc}`, instructions: "", contextItemIds: [] }
      : { targetDoc, docState: "missing", suggestedDisposition: "create", purpose: `Draft ${targetDoc} from repository evidence`, instructions: bootstrapInstructions(targetDoc), contextItemIds: itemIds };
  });
  return { projectId: analysis.projectId, ruleVersion: PROJECT_TRUTH_BOOTSTRAP_RULE_VERSION, targets };
}
```

Planner authority (binding invariant): this function iterates `input.plan.targets` — **never** `input.proposals`. A proposal with no matching create-target is discarded (AI cannot invent a document); a create-target with no proposal still yields a `proposal: null` draft (AI cannot silently skip a target). The nth-proposal↔nth-create-target pairing below is a **v0.3.2 implementation detail** valid only under the deterministic `StubAiProvider`; future hardening (design doc) replaces it with explicit `targetDoc` matching. Do not implement that now.

```typescript
// Match a generated proposal to a planned target. Proposals fill planner-selected slots ONLY;
// the mapper iterates plan.targets (planner authority), pairing nth create-target ↔ nth proposal.
// (Ordering pairing is a v0.3.2 stub-only detail — see design "Future hardening".)
export function mapBootstrapDrafts(input: {
  plan: BootstrapPlan;
  proposals: AiProposal[];
  inventory: ProjectEvidenceInventory;
}): { drafts: ProjectTruthDraft[]; unresolvedInfo: string[] } {
  const knownPaths = new Set(input.inventory.items.map(i => i.relativePath));
  const createTargets = input.plan.targets.filter(t => t.suggestedDisposition === "create");
  // Deterministic pairing: nth create-target ↔ nth proposal. Extra proposals are ignored (no duplicate docs).
  const proposalByDoc = new Map<string, AiProposal>();
  createTargets.forEach((t, i) => { if (input.proposals[i]) proposalByDoc.set(t.targetDoc, input.proposals[i]); });

  const unresolvedInfo: string[] = [];
  const drafts: ProjectTruthDraft[] = input.plan.targets.map((t): ProjectTruthDraft => {
    const proposal = proposalByDoc.get(t.targetDoc) ?? null;
    if (!proposal) return { targetDoc: t.targetDoc, docState: t.docState, suggestedDisposition: t.suggestedDisposition, proposal: null, verifiedEvidence: [], ownerInputNeeded: [] };
    const verifiedEvidence = proposal.provenance.evidence.filter(e => e.ref !== null && knownPaths.has(e.ref));
    const ownerInputNeeded: string[] = [];
    for (const e of proposal.provenance.evidence) {
      if (e.ref !== null && !knownPaths.has(e.ref)) ownerInputNeeded.push(`Unverifiable citation for ${t.targetDoc}: ${e.ref} (not in project evidence) — needs owner confirmation.`);
    }
    if (proposal.provenance.inferred || verifiedEvidence.length === 0) ownerInputNeeded.push(`${t.targetDoc}: owner intent could not be inferred from repository evidence — owner input required.`);
    for (const s of ownerInputNeeded) if (!unresolvedInfo.includes(s)) unresolvedInfo.push(s);
    return { targetDoc: t.targetDoc, docState: t.docState, suggestedDisposition: t.suggestedDisposition, proposal, verifiedEvidence, ownerInputNeeded };
  });
  return { drafts, unresolvedInfo };
}
```

```typescript
/**
 * Async orchestrator: plan → generate (AiService) → map/validate → assemble.
 * Holds an AiService and NO repository — structurally cannot read or write vault.db.
 */
export class ProjectTruthBootstrapService {
  private readonly ai: AiService;
  private readonly now: () => string;
  constructor(ai: AiService, options?: { now?: () => string }) {
    this.ai = ai;
    this.now = options?.now ?? nowIso;
  }

  async bootstrap(analysis: ProjectContextAnalysis): Promise<AiResult<ProjectTruthBootstrapResult>> {
    const plan = planProjectTruthBootstrap(analysis);
    const createTargets = plan.targets.filter(t => t.suggestedDisposition === "create");

    let proposals: AiProposal[] = [];
    let provider: string | null = null;
    let model: string | null = null;

    if (createTargets.length > 0) {
      const instructions = createTargets.map(t => `[${t.targetDoc}] ${t.instructions}`).join("\n");
      const response = await this.ai.propose({
        projectId: analysis.projectId,
        purpose: `Bootstrap missing Project Truth for ${analysis.projectId}`,
        context: analysis.contextPackage,
        desiredKind: "project_truth",
        instructions,
      });
      if (!response.ok) return response; // typed AiError, nothing mutated
      proposals = response.value.proposals;
      provider = response.value.provider;
      model = response.value.model;
    }

    const { drafts, unresolvedInfo } = mapBootstrapDrafts({ plan, proposals, inventory: analysis.inventory });
    return {
      ok: true,
      value: {
        projectId: analysis.projectId,
        ruleVersion: PROJECT_TRUTH_BOOTSTRAP_RULE_VERSION,
        readiness: analysis.readiness,
        drafts,
        unresolvedInfo,
        provider,
        model,
        generatedAt: this.now(),
```
